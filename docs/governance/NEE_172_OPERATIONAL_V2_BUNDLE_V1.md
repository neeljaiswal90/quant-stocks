# NEE-172 operational V2 bundle V1

This artifact is the single deterministic selector for the registered NEE-119,
NEE-120, and NEE-121 V2 contracts. It verifies the exact contract, schema, and
manifest bytes, invokes each native verifier, verifies every child-manifest leaf,
and checks the registered NEE-120 to NEE-121 hash, pointer, and return-coordinate
boundary.

Successful verification proves integrity and materialization only. All fourteen
registered blockers remain active. It does not establish cross-contract semantic
approval, production evidence, a calendar or session vector, inference or capacity
implementation, N_eff, DSR, empirical performance, alpha, a final freeze receipt,
prospective eligibility, downstream authorization, live orders, or M0 completion.

The protected-main receipt in the bundle identifies the publication of the three
component contracts. It is not the final NEE-121 freeze anchor or receipt. The bundle
never discovers a `latest` file and never merges overlays; consumers select this exact
bundle by path and hash.
